# Diplom_3
## UI Тесты "Stellar Burgers"
1. Установите зависимости:
pip install -r requirements.txt
2. Запустить все тесты и записать отчет:
pytest tests --alluredir=allure-results

### Структура
- в папке locators расположены все необходиые локаторы, разделленые по страницам
- папка pages описывает страницы
- в папке test расположены сами тесты
- папка url содержит URL главной страный тестируемого сайта
- папка data содержит данные для авторизации пользователя
